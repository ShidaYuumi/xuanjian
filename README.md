# 玄鉴仙族 · 三千大道观想图

基于 React + Vite + Three.js 的修仙道统 3D 探索页面。中央玄鉴、道统晶石与神通法印由 WebGL 绘制，可拖曳旋转星图、点选道统或神通观想；页面另提供分类筛选、道统/神通搜索、道统档案、十二炁对照与 58 道统索引。移动端可使用星图下方的道统条快速切换。动画尊重系统的减少动态效果设置，WebGL 不可用时仍可通过道统条和档案查阅内容。

## 启动

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 内容说明

- 按公开索引展示阴阳 6 道、五德 26 道、十二炁 12 道、三雷 3 道、并古 9 道及独立道统 2 道。
- 道统与神通名称取自公开的《玄鉴仙族 Wiki》「道统丨神通丨仙基」汇总，少数别名/替参未另作重复条目。
- 道统权柄摘要仅作简述；神通的实际效用、功法关联与剧情状态请以小说正文为准。
- “十二炁六组观法”是便于阅读的书友归纳；五德五现、青宣的归属及清邃六轮论存在不同道论口径，页面以归纳/推演标注，不作为原文唯一结论。
